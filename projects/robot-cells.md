# 디지털 트윈과 협동 작업 셀

[포트폴리오 처음으로](../README.md)

## 이음 · 2026.03

팀은 Isaac Sim에서 주문 DB, AGV, 적재·하차용 UR10 두 대, 컨베이어와 배송 드론을 연결했습니다. 주문을 개별 작업으로 나누고 마지막 상자가 컨베이어에 안착하면 배송을 시작하는 흐름입니다.

**개인 담당은 PM과 시스템 통합**이었습니다. 경로 계획, SLAM·내비게이션, 개별 제어 모듈은 팀 역할표에 따라 구분합니다. 작업 사이에서 어떤 완료 신호가 다음 장치의 시작 조건이 되는지를 중심으로 설명할 수 있습니다.

## 지음 · 2026.02

사용자가 설계도에 블록을 배치하고 저장·불러오기를 수행하면 블록 정보가 협동로봇의 집기·배치 공정으로 넘어가는 프로젝트였습니다. **PM, UI, 시스템 통합, 협업 시스템**을 담당했습니다. 블록 인식과 개별 로봇팔 제어는 팀원의 모듈이었습니다.

## 따따로 · 2026.01

팀은 키오스크의 이미지·문구를 레터링 경로로 바꾸고 로봇팔이 작업대에서 도구를 준비해 케이크에 그리는 셀을 구성했습니다. **PM·UI, 로봇 제어와 안전 복구**를 맡았습니다. 경로 생성과 레터링 알고리즘은 팀의 별도 파트였습니다.

작업 재개를 검증한다면 작업 ID, 마지막 완료 단계, 파지 상태, UI 표시를 함께 기록하겠습니다. 집기 전과 집기 후를 구분하지 않으면 재개 시 한 공정을 두 번 실행할 수 있기 때문입니다.
